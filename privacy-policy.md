# Privacy Policy for ASCE Memo RAG Assistant (Yasmin Korin)

Last updated: January 2026

This Privacy Policy describes how data is handled when you use the ASCE Memo RAG Assistant (“the GPT”) created by Yasmin Korin. This GPT uses an external Action that sends user queries to a publicly accessible Retrieval-Augmented Generation (RAG) microservice hosted at:
https://asce-it-recommendations-lerner-lam.onrender.com

The goal of this GPT is to retrieve relevant sections of a publicly available memo (the ASCE IT Recommendations by Eva Lerner-Lam) and provide grounded, citation-like answers based on that content.

---

## 1. Information We Collect

The GPT temporarily collects:
- The text of your query (the question you type)
- Any configuration parameters required by the Action (e.g., `top_k`)
- Retrieval results generated by the RAG microservice

No personal identifying information (PII) is required or collected intentionally.

---

## 2. How Your Data Is Used

Your query is sent to the RAG API solely for:
- Performing vector similarity search
- Retrieving relevant chunks from the embedded memo
- Constructing a context string used to answer your question

The microservice does *not* store or log user queries. It processes them in memory and returns a response.

The GPT then uses the retrieved context to generate an answer.

---

## 3. Data Retention

- The RAG microservice does **not** store user queries.
- No user data is saved in any database.
- All input is processed in real time and discarded immediately after generating a response.

---

## 4. Third-Party Services

Your query is processed through:
- OpenAI’s GPT systems  
- A custom microservice hosted on Render  

All interactions with OpenAI follow the OpenAI privacy policy.  
Render may maintain routine operational logs as part of their service, but the microservice itself does not intentionally store user inputs.

---

## 5. Children’s Privacy

This GPT is not directed to minors under 13. No personal data is collected.

---

## 6. Security

The RAG microservice is read-only and does not store any user data. API endpoints use HTTPS encryption provided by Render.

---

## 7. Changes to This Policy

Any changes will be published to the same URL.
